# archspec/5 契约（架构图）

flow-canvas 多图类型引擎 · 架构图排版契约。v5 在 v4 语义模型基础上补齐**几何与可读性自动验收**（Codex 第二轮 8 维度中剩余的硬指标），并扩展路由容量。v4 → v5 破坏性变更：报告新增 `labelCollisions` 硬门槛；路由族扩容（左右线廊、底部总线、侧端口出线）；节点同层统一高度；对齐迭代加强；布局失败自动扩画布重排。

## 输入

与 v4 相同（mermaid 子集 + 引擎指令 `title/view/scope/version/todo`、嵌套 subgraph 系统边界、外部实体、`[A1]` 注释锚点、节点三层文字、`-->`/`-.->` 同步/异步）。无语法变更。

## 布局规则（v5 增量）

1. **拓扑列对齐加强**：邻接重心 6 轮迭代 + 行内最小间隔双扫（父居中于子组、兄弟对称、外部实体与其内部目标对齐直落）。
2. **同级节点统一高度**：泳道内节点高度取泳道最大值（同类节点尺寸稳定，端口与文字不随文本漂移）；数据存储圆柱体最小高度 44px 保证内部文字安全区，椭圆 rx/ry 随宽高自适应（不再呈沙漏状）。
3. **路由族**（按折弯数优先，候选搜索零交叉）：
   - 直落：列对齐的父子边/外部边垂直直线（0 折弯）；
   - 总线：相邻泳道 V-H-V（≤2 折弯）；
   - 间隙走廊：泳道内跳级（上侧或下侧）；
   - **左右线廊**：跨层/外部边从泳道最左/最右节点侧端口出线，绕开饱和间隙；
   - **底部总线**：所有走底的边共享同一 y（T 形汇入端点互不计数，共线重叠不计）；
   - **顶部走廊带**：加密通道（7px 档），外部边在既有通道间穿插。
4. **边标签**：钳制在水平段内并避开两端垂直列；放不下时竖排源侧；同带自动分轨；标签不含引号。
5. **自动验收（硬门槛，任一非 0 拒绝产出）**：
   - crossings：线段交叉（端点 T 形汇入不计）；
   - overlaps：节点框重叠；
   - textOverflow：节点文字/标题/元信息越界；
   - **labelCollisions**：文本×文本 / 文本×连线 / 文本×节点框（标签自身路由与端点节点除外）；
   - 折弯 >2 与无标签边入 warnings（不阻断）。
6. **失败自愈**：交叉/标签碰撞无法消除时自动扩宽泳道间隙（60→100px）重排一次；仍失败 → 报「形态超限」拒绝产出并建议拆图/折叠细节/改用 mermaid 原生（诚实降级，不产烂图）。

## 输出 SVG 契约

- 根元素：`<svg data-archspec="5" viewBox="0 0 W H">`
- 节点：`<g class="node" id="arch-{id}" data-node="{id}" data-style="{external|container|datastore}">`
- 系统边界 `<g class="boundary">`、泳道 `<g class="lane">`、图例 `<g class="legend">`、待确认项 `<g class="todo">`、锚点徽章 `class="note-badge"`、同步 `#arw` / 异步 `#arw-open` marker。

## 质检

统一 `--check` 报告字段新增 `labelCollisions` / `labelCollision_points`。`crossings` / `overlaps` / `textOverflow` / `labelCollisions` 任一非 0 即不合格。字号 ≥10px、线宽 ≥1.4 为可读性硬阈值。

## 容量边界（诚实声明）

中间列节点被相邻长跨度总线的水平段在上下两侧完全封死、且左右被同级节点阻挡时，该节点的跨层边在固定列位置下不存在零交叉正交路由——引擎在穷举全部路由族 + 自动扩画布后明确降级并提示拆图。这正是「无法满足时拆图或折叠细节」的引擎侧执行。
