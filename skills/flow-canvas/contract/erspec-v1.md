# erspec/1 契约（ER 图）

flow-canvas 多图类型引擎 · ER 图排版契约。破坏性变更时主版本 +1。

## 输入：mermaid erDiagram 子集

```
erDiagram
  CUSTOMER ||--o{ ORDER : "下订单"
  CUSTOMER {
    string id PK
    string name "昵称"
    int age
  }
  ORDER {
    string id PK
    string customer_id FK
    date created_at
  }
```

- 实体：`NAME { 属性行... }`；属性行 = `类型 属性名 [PK|FK] ["注释"]`（PK 下划线、FK 斜体渲染）。
- 关系：`A 基数--基数 B : "标签"`；左右各一个基数记号（`||`、`o|`、`|{`、`o{`、`}|` 中的组合）。
- 不支持：属性定义缺失、未知基数记号、emoji → 报「形态超限」错误降级。

## 布局规则

1. 实体 = 表格块：表头 + 属性行（行高 = 文字行高）；列宽 = 表头/属性/基数标签最宽者 + 边距。
2. 实体横向排列；初始按声明序，用 barycenter 重排（实体位置 = 邻居平均序号，迭代 2~4 轮）消除边交叉。
3. 实体间隔 = 最宽实体 + 最宽基数标签 + 通道宽。
4. 边：源右端口 → 目标左端口；直线优先，与其他边或实体相交时改正交折线（水平 → 垂直 → 水平，走实体间通道）；每条边独立 y 走廊，同侧端口错位 ±8px。
5. **关系标签长度**：标签走廊约 68px，`"标签"` **≤ 4 个汉字**（超出会被质检以 textOverflow 拦下——缩短标签或改用表格讲解）。
6. 重排后仍有交叉 → 报「形态超限」错误降级。

## 输出 SVG 契约

- 根元素：`<svg data-erspec="1" viewBox="0 0 W H">`
- 实体：`<g class="entity" id="er-{id}">`：表头 rect + 属性行 text + 行分隔线

## 质检

统一 `--check` 报告字段；块重叠 0、边交叉 0、文字溢出 0，任一非 0 拒绝产出并降级。
实体数 > 8 或交叉无法消除 → 报「形态超限」错误降级。
